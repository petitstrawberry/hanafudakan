# ハイパー調整・検証記録（2026-09-23）

採用ルール：選んだ役だけを賭け金へ移し、双方の取り札を清算して48枚で完全再配布。相手が先手。契約・花力・成長倍率・HPは持ち越す。契約者のあがりには、倍率前の役点合計が契約元の最大役点を超え、最後の契約後にこいこいする必要がある。こいこい前の重ねがけは可能。未契約者は相手の3CHAIN以降、各手番1回の反撃めくりを得る。通常のこいこいには影響しない。

## 比較方法

札の選択は全戦略で同じ `move_value`。差は役成立後の判断のみ。各組み合わせを seed 0〜1999、左右を入れ替えて4,000試合（3局制）ずつ実行した。各再配布案につき3組み合わせ、12,000試合・36,000局。3案を比較したあと、連鎖カウンター上限で同じボーナスが繰り返し発火する点を直し、採用案をさらに12,000試合で再検証した。

- 即あがり：役成立時に必ず得点確定。契約・こいこいをしない。
- 積極契約：契約可能なら最初の候補を必ず契約し、それ以外はあがる。
- 状況判断：CPU本体。捨てる役点と選択役、獲得予告55文未満、HP6超を条件に契約し、それ以外はあがる／こいこいを選ぶ。

| 清算方式 | 積極契約 対 即あがり | 状況判断 対 即あがり | 状況判断 対 積極契約 |
| --- | ---: | ---: | ---: |
| 相手の全取り札を保持 | 5.88% | 9.10% | 63.05% |
| 双方を清算 | 54.30% | 57.83% | 51.73% |
| 相手の最上位の成立役だけ保持 | 54.30% | 57.83% | 52.52% |

表は左側戦略の試合勝率（引き分けも分母に含む）。全取り札を相手に残す案は契約側に不利すぎた。成立役だけ保持する案と全清算は近く、条件分岐が少なく配札が必ず8/8/8/24になる全清算を採用。即あがり相手では相手の成立役がまだないことが多く、後者2案の結果が一致している。

## 連鎖への反撃とあがり条件（2026-09-23追試）

この時点では、連鎖の追加めくりと倍率を維持し、契約者だけが契約元の役点以上の単独の役を作らないと「あがる」を選べないようにした。複数契約では最大値で、合計値にはしない。K.O.はこの条件の対象外。未契約側は相手が3CHAIN以上になった後、通常めくりの後に各手番1回だけ反撃めくりを得る。これによりハイパー返しを待たずに札と役を取り返せる。以下の「採用版」はこの当時の「以上」判定による結果である。

## 役点を合算し、契約後のこいこいを必須に変更（2026-09-23）

## Issue #9：光契約・役撃・HPの初回案（2026-10-01）

以下は光契約だけを変更した時点の記録。現行の全契約・CHAIN調整と実サーバーE2Eは末尾の「全契約の再設計」を参照。

基準コミット `82246dbd8ab98e5fe09c4e7eba8e7dcc3c58e006`。従来の攻撃は獲得札数＋3CHAIN以上で1で、成立した役の強さを使わなかった。光4役はいずれもstorm・HP18で、犠牲役点が高いほどあがり条件だけが厳しくなっていた。これを修羅場／雨罠／光壁／天威の4種類（全契約12種類）に分けた。各手番の初撃に限る契約威力、公開罠、初撃防御、被ダメージ増のリスクを使い分ける。

新ルールは札枚数＋役の新成立・増点（最大10）＋CHAIN＋初撃＋天威の被ダメージ増を16までに制限してから光壁の防御を引く。役撃は光の上位移行で差分だけ加算する。初撃威力を追加めくりのたびに再発動させない。倍率・花力・賭け金は攻撃に使わない。全て整数で初撃の役点÷3のみ切り捨て。内訳、威力、実際のHP減少をサーバーが予告と公開イベントに載せ、クライアントとログで区別する。手番欄の「攻撃履歴」から直近8回の内訳を読める。

罠は再配布後の場から自分のplay phaseに任意指定する。各手番1回・1人1枚、全員に公開。自分が取れば解除、相手なら4攻撃。次の自分手番・再配布・決着で消える。罠と札取得の攻撃は同時に解決してからK.O.を判定し、相打ちは配当0。攻撃側の死亡も追加めくりを止める。再配布回数は契約上限により双方合計6までで、HP回復は加えない。

## 全契約の再設計とCHAINの維持（2026-10-01、最終仕様）

「追加めくりが多く、効果の違いがわからない」と「CHAIN感は維持したい」の両方を反映した。共通の最初の取得めくり1回は維持する。3CHAINごとの成長倍率は各手番2回まで、CHAINの追加めくりは各手番1回へ制限する。連筆で区切りを飛び越しても成長と演出を発動する。札の連続移動、音、連鎖の持ち越しを維持し、能力ごとに長い説明演出は追加しない。

固有効果として追加めくりを生むのは猪鹿蝶の暴走だけ。その他の契約は異なる札・局面・勝ち方を選ばせる。全契約に再配布・相手先手・賭け金喪失・あがり条件のリスクは残る。タネ・短冊・カスは実際の犠牲役点を強さに使い、1〜3に制限する。強さを3で止めた後も実役点は賭け金・あがり条件に使う。

- 伏兵：3種類（徴収・暴露・足枷）から各手番2種類を抽選し、その中から選択。取消・再接続で引き直さず、1人1枚・1手番1配置。敵の取得にだけ発動し、次の所有者手番開始で失効。存在は公開、種類は発動まで所有者だけに配信する。

## 2026-10-01 伏兵を3種から8種へ拡張

罠の種類が少ないというフィードバックを受け、従来の徴収・暴露・足枷に奪還・すり替え・徴税・凶運・焼却を追加した。各手番に8種から重複なしで2候補を抽選し、所有者が1つを選ぶ。種類を増やしても1人1枚・1手番1配置・次の自分手番で失効という頻度は変えない。手札交換は山札の底へ、倍率妨害はCHAIN値と追加めくりを維持する。

| 追加効果 | 数値と制限 | 強くなる局面 |
| --- | --- | --- |
| 奪還 | 罠札1枚だけ所有者へ。相手の取得報酬・役・HP攻撃は移動後に計算 | 役の最後の札、HP戦の役撃を狙う取得 |
| すり替え | 残り手札のランダム1枚と山札の底を交換。空なら0 | 相手が手札に仕込んだ札が多いとき |
| 徴税 | 踏んだ手番の勝利配当25%を奪う。切り捨て、こいこいで解除 | 高配当の決着直前。あがりと継続の選択が変わる |
| 凶運 | 当該手番の倍率−0.5、最低×0.5 | 現在の配当を削りたいとき。成長は止めない |
| 焼却 | 蓄積boost最大0.5を削除、再成長可能 | 相手が既に成長した後。基礎倍率・CHAIN倍率は削らない |

奪還は相手の役成立も取り消せるため、場札全体や相手の既存取り札は奪わない。徴税は永久の得点債務にせず、その手番の決着に限定する。凶運・足枷・焼却はそれぞれ「今の倍率」「これからの成長」「既に貯めた成長」を対象とし、同じ倍率差の名称違いにしない。足枷によって停止するこいこいの倍率成長も、通常は手番終了で解除する。

伏せ罠を踏むHP予告は `uncertain` を付け、罠効果を除外して計算する。隠れた種類を予告差やCPUの評価から推測できないようにした。例：赤短を成立させる取得の予告7に対し奪還が発動すると、保持札1・役撃0の実攻撃1になる。UIは「罠効果未反映」とその可能性を表示し、発動後の内訳は実値を記録する。

### 数値検証（8種）

## 2026-10-01 非公開の持続罠・1局3回とルーレット

以前の配置場所が公開で次の自分手番に消える仕様を変更した。ユーザー指定は「1局3回まで」。配置時に1回消費し、手番をまたいで取得されるまで持続する。未発動の罠の移動・重ね置きは禁止。自分で取得・再配布で解除されても回数は戻さず、別契約や再配布による再補充はしない。設置後に毎手番の操作が必要な仕様と無制限の補充を廃止した。

snapshotの印・種類・設置可否・残回数・候補は本人だけに配信する。相手・観戦者のsnapshot、公開ログ・移動イベントから設置を隠す。相手が伏兵を持つ場合のHP予告は、設置の有無・位置によらず全取得候補に罠未反映フラグを付ける。発動した札・種類・実効果は従来の公開発動演出で見せる。

8種から抽選された2候補を、2リールのルーレットが回って止まる演出で公開する。結果はサーバーで確定し、取消・再接続で引き直せない。残回数を本人の状態と選択パネルに表示。動きを減らす設定では演出を短縮する。

自然CPU2,000局は中央値33操作・95%点51・最大69、流局36、最大CHAIN23で全局終了。500seed×席交換の強制光契約4,000局も全局終了。雨四光は勝利665/1,000（毎手番補充時655）、手番中央値22（従来21）、発動707回（従来1,984）。発動頻度を抑えつつ、持続によって大きな弱体化は観測していない。ただし候補の抽選タイミングが変わり乱数消費も変わるため、勝率差を単独の因果とは扱わない。
