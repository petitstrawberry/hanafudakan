## Changes and redistribution

The 48 imported SVG files are byte-for-byte identical to the files at the pinned upstream revision. Their filenames have been changed to `0.svg` through `47.svg` to match the game's stable card IDs. No illustration, color, SVG markup, or embedded metadata was changed. Import date: 2026-09-22.

CC BY-SA 4.0 permits sharing and adaptation under its conditions. Preserve the artist and recolor credits, the source and license links, and any modification notices when redistributing this artwork. Adapted artwork must be shared under CC BY-SA 4.0 as required by that license. There is no implied endorsement of this application by the artists.

`back.svg` is original artwork created for this Hana Fuda Kan project, not an asset from the recolor repository. This import did not alter the card back. Its checksum is recorded separately in the manifest.

Every imported face and font is self-hosted. External links in these credits are references only; rendering the deck does not contact a CDN.

[manifest.json](manifest.json) records the source file and pinned URL, original graphic URL, SVG dimensions, upstream Git blob SHA-1 and SHA-256 for every card. The Git object hash was checked against the pinned upstream tree before import; local SVGs were parsed and checked for scripts and external image references.
